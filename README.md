## 🛠️ Building Locally

- Prerequisites: Node.js (>=18), Python (>=3.9 optional), Docker (for full deployment)
- Fork the repository and clone locally.
- Run:  
  - `npm install`  
  - `npm run dev`  
- Access at `localhost:3000`
- See `docs/` directory for API and schema references.
